## 2. 产品定义

### 2.1 产品目标

1. **核心闭环可运行**：学生能浏览课程 → 抢课 → 查看课表 → 参加考试 → 查看成绩，形成完整教学闭环
2. **多角色协作**：5 个角色（学生/教师/教务/管理员/题库管理员）各自拥有独立工作台与专属功能
3. **Figma 紫色毛玻璃视觉体验**：对标 auto-project 项目的 Figma 设计风格，提供现代、沉浸式 UI

### 2.2 用户故事

#### 学生（Student）

| 编号 | 故事 | 验收条件 |
|------|------|---------|
| STU-01 | As a 学生, I want 在课程广场浏览和搜索课程, so that 我能快速找到感兴趣的课程 | 支持分类筛选 + 关键词搜索，展示课程名/教师/时间/容量/已选人数 |
| STU-02 | As a 学生, I want 一键选课/退课, so that 我能灵活管理本学期课程安排 | 点击选课按钮即扣减名额（先到先得），退课后名额立即释放 |
| STU-03 | As a 学生, I want 查看我的周课表, so that 我能合理安排学习时间 | 周视图展示周一至周日课程，含节次/地点/教师 |
| STU-04 | As a 学生, I want 在线参加考试并即时看到客观题分数, so that 我能了解自己的学习效果 | 限时作答，提交后客观题自动评分并展示结果 |
| STU-05 | As a 学生, I want 查看我的所有课程成绩, so that 我能追踪学业进展 | 列表展示课程名/学分/成绩/GPA |

#### 教师（Teacher）

| 编号 | 故事 | 验收条件 |
|------|------|---------|
| TEA-01 | As a 教师, I want 为我的课程录入成绩, so that 学生能及时获取成绩 | 按课程-学生列表录入或批量导入，支持百分制/五级制 |
| TEA-02 | As a 教师, I want 管理题库（CRUD）, so that 我能维护考试题目 | 支持单选/多选/判断/填空题型，批量导入导出 |

#### 教务（Academic Staff）

| 编号 | 故事 | 验收条件 |
|------|------|---------|
| ACA-01 | As a 教务人员, I want 审核教师提交的课程, so that 确保课程质量与合规性 | 待审列表 → 查看详情 → 通过/驳回（含理由） |
| ACA-02 | As a 教务人员, I want 配置选课轮次, so that 控制系统在特定时段开放选课 | 设置轮次起止时间、参与年级、最大选课门数 |

#### 管理员（Admin）

| 编号 | 故事 | 验收条件 |
|------|------|---------|
| ADM-01 | As a 管理员, I want 管理所有用户账号, so that 我能维护系统用户体系 | CRUD + 启用/禁用 + 角色分配 |
| ADM-02 | As a 管理员, I want 配置 RBAC 权限, so that 各角色只能访问授权功能 | 角色-菜单绑定，权限精确到按钮级 |

#### 题库管理员（QB Admin）

| 编号 | 故事 | 验收条件 |
|------|------|---------|
| QB-01 | As a 题库管理员, I want 管理全局题库和知识点体系, so that 试题资源得到统一维护 | 试题 CRUD + 知识点三级分类 + 批量导入 |

## 3. 功能需求池

### P0 — 无此功能系统不可用（Must Have）

| 编号 | 模块 | 需求 | 验收指标 |
|------|------|------|---------|
| F-P0-01 | 认证 | JWT 登录/登出/Token 刷新，密码错误 5 次锁定 30 分钟 | 所有角色可登录，未登录无法访问任何功能页 |
| F-P0-02 | RBAC | 5 角色权限隔离，后端接口 + 前端路由双重校验 | 学生无法访问教师/管理端 API |
| F-P0-03 | 课程广场 | 分页展示所有审核通过的课程，支持分类筛选 + 关键词搜索 | 500 门课程列表加载 ≤ 1s |
| F-P0-04 | 选课 | 抢课制：点击选课 → Redis 原子扣减名额 → 写入选课记录 | 50 容量课程，200 人同时抢，无超卖 |
| F-P0-05 | 退课 | 学生退课 → Redis 原子归还名额 → 更新选课状态 | 退课成功后立即释放名额 |
| F-P0-06 | 课表 | 学生/教师周视图课表 | 课程信息完整（名称/时间/地点/教师） |
| F-P0-07 | 课程审核 | 教务审核教师提交的课程申请 | 通过/驳回，状态流转正确 |

### P1 — 核心业务流程必需（Should Have）

| 编号 | 模块 | 需求 | 验收指标 |
|------|------|------|---------|
| F-P1-01 | 用户管理 | 管理员对用户 CRUD + 状态管理 | 创建/编辑/禁用/删除 |
| F-P1-02 | 成绩录入 | 教师录入/批量导入成绩 | Excel 导入解析正确，支持百分制/五级制 |
| F-P1-03 | 成绩查询 | 学生查看本人所有课程成绩 | 列表含课程名/学分/成绩/GPA |
| F-P1-04 | 考试 | 固定试卷考试：开始 → 限时作答 → 提交 → 客观题自动评分 | 倒计时准确，客观题批改 100% 正确 |
| F-P1-05 | 题库 CRUD | 教师/题库管理员增删改查试题 | 支持单选/多选/判断/填空 |
| F-P1-06 | 题库导入 | Excel 批量导入试题 | 支持模板下载，解析错误行提示 |

### P2 — 显著提升体验（Nice to Have）

| 编号 | 模块 | 需求 | 验收指标 |
|------|------|------|---------|

| F-P2-05 | 深色模式 | 全局深色模式切换 | 所有页面适配深色主题 |

## 4. UI/UX 设计规范

> **设计基准**：对标 auto-project 项目的 Figma 紫色系毛玻璃风格。

### 4.1 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| **主色** | `#8b5cf6` | 按钮、链接、激活态、品牌标识 |
| **主色深** | `#7c3aed` | Hover 态、渐变终点 |
| **主色浅** | `#a78bfa` | 次要元素、光效 |
| **背景** | `#0f0f23`（深色）/ `#f5f3ff`（浅色） | 页面底层 |
| **卡片背景** | `rgba(255,255,255,0.06)` 深色 / `rgba(255,255,255,0.7)` 浅色 | 毛玻璃卡片 |
| **文字主** | `#ffffff`（深色）/ `#1a1a2e`（浅色） | 标题 |
| **文字辅** | `rgba(255,255,255,0.6)` / `rgba(0,0,0,0.5)` | 描述信息 |
| **成功/警告/危险** | `#10b981` / `#f59e0b` / `#ef4444` | 状态语义色 |

### 4.2 毛玻璃规范

```
卡片/侧边栏/顶栏 CSS 核心：
- background: rgba(255, 255, 255, 0.06);
- backdrop-filter: blur(20px) saturate(180%);
- border: 1px solid rgba(255, 255, 255, 0.08);
- border-radius: 16px;
```

### 4.3 四层阴影规范

```css
box-shadow:
  0 0 40px rgba(139, 92, 246, 0.15),    /* Ambient 环境光（紫色） */
  0 8px 32px rgba(0, 0, 0, 0.25),       /* Directional 定向 */
  0 2px 4px rgba(0, 0, 0, 0.15),        /* Contact 紧密 */
  inset 0 1px 0 rgba(255, 255, 255, 0.1) /* Rim Light 顶部内发光 */
;
/* 底部暗角通过伪元素实现： */
&::after {
  content: '';
  position: absolute; bottom: 0; left: 0; right: 0;
  height: 1px;
  background: linear-gradient(90deg, transparent, rgba(0,0,0,0.1), transparent);
}
```

### 4.4 字体规范

- **字体**：Space Grotesk（英文/数字）+ 系统默认中文字体栈
- **font-family**: `'Space Grotesk', -apple-system, BlinkMacSystemFont, 'PingFang SC', 'Microsoft YaHei', sans-serif`
- 标题使用 `font-weight: 600`，正文使用 `font-weight: 400`
- 引入方式：Google Fonts CDN 或本地 `@font-face`

### 4.5 背景效果

- **3D 毛玻璃背景**：多层半透明渐变叠加
- **薄磨砂玻璃**：底部固定一个 `backdrop-filter: blur(100px)` 的全屏层
- **5 颗果冻光球**：
  - 主紫色球（#8b5cf6）、青色球（#06b6d4）、粉色球（#ec4899）、琥珀球（#f59e0b）、蓝紫球（#6366f1）
  - 尺寸 200-400px，`border-radius: 50%`，`filter: blur(80px)`
  - 使用 CSS `@keyframes orbFloat` 实现缓慢漂浮动画（周期 15-25s，各不相同）
  - `position: fixed`，`z-index: -1`，`opacity: 0.3-0.6`

### 4.6 侧边栏 & 顶栏

```
侧边栏：
- background: rgba(15, 15, 35, 0.75);
- backdrop-filter: blur(24px) saturate(180%);
- border-right: 1px solid rgba(255,255,255,0.06);
- 右侧有紫色环境光阴影

顶栏：
- background: rgba(15, 15, 35, 0.6);
- backdrop-filter: blur(16px);
- border-bottom: 1px solid rgba(255,255,255,0.06);
```

### 4.7 图标规范

- **风格**：黏土/塑料质感 3D 图标
- **实现**：径向渐变背景 + 内阴影 + 光泽高光 + 软阴影
- **hover 效果**：`transform: translateY(-2px) rotate(5deg)` + 紫色外发光（`box-shadow: 0 0 16px rgba(139,92,246,0.5)`）
- **过渡**：`transition: all 0.3s cubic-bezier(0.34, 1.56, 0.64, 1)`

### 4.8 菜单项动效

- **激活菜单项**：每 3 秒内发光脉动一次（`@keyframes activePulse`，`box-shadow` 从 0 → 亮紫 → 0）
- **悬浮菜单项**：半透明紫光条从左滑到右（`::before` 伪元素 + `@keyframes menuSweep`，0.6s duration）

### 4.9 呼吸灯 & 光圈脉冲

- 通知红点：`@keyframes breathe` 缩放 1 → 1.3 → 1，周期 2s
- 按钮主色光圈：`@keyframes pulseRing`，`box-shadow` 扩散 + 淡出

### 4.10 表单规范

- 输入框/选择器：圆角 12px，半透明毛玻璃背景
- 聚焦态：紫色边框 + 外发光（`box-shadow: 0 0 0 3px rgba(139,92,246,0.3)`）
- 按钮：`border-radius: 12px`，渐变紫色背景，hover 上浮 + 加深

### 4.11 自定义光标

- 默认：`cursor.svg`（自定义紫色圆形光标）
- Hover 可交互元素：`cursor-hover.svg`（带外发光的大圆）
- 来源：从 auto-project 项目复制

### 4.12 深色模式

- 通过 CSS 变量切换，所有颜色应定义在 `:root` 和 `[data-theme="dark"]` 中
- 切换按钮在顶栏右上角
- 默认跟随系统偏好
